# Lesson 12 Student README

This file contains the student-facing usage order for this lesson bundle.

1. Start with `remote-data-build-checklist.md` during class.
2. Stay on that checklist as the main path unless you need help with one specific issue.
3. Check `starting-state-reference.md` only if you are unsure whether your project is ready.
4. Use `api-fetch-reference.md`, `starter-snippets.md`, and `troubleshooting-checklist.md` only when the checklist tells you to inspect a request step, log, or recovery path.
5. Record your current outcome in `fetch-status-tracker.md` if instructed.
6. Use the reference path in `example/` only if the instructor directs you to inspect it.
7. Complete `exercise.md` after class.

## Important Note
Students should not begin with `exercise.md`. The guided in-class fetch build and support references come first.
