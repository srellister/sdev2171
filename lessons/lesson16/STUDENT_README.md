# Lesson 16 Student README

This file contains the student-facing usage order for this lesson bundle.

1. Start with `starting-state-reference.md`.
2. Move into `context-build-checklist.md` as the main path during class.
3. Use `provider-placement-reference.md`, `context-flow-reference.md`, `starter-snippets.md`, and `troubleshooting-checklist.md` only when the checklist tells you to inspect a Context setup or recovery step.
4. Record your current outcome in `context-status-tracker.md` if instructed.
5. Use the reference path in `example/` only if the instructor directs you to inspect it.
6. Complete `exercise.md` after class.

## Important Note
Students should keep the shared-state scope small in this lesson. The goal is to move one cross-screen feature into Context clearly, not to turn every local value into shared state.
