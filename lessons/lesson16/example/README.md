# Lesson 16 Example Projects

This folder contains the instructor reference assets for lesson 16.

- `context-state-reference/`
  A known-good Expo Router app that moves the selected-step feature into a shared Context provider so the details and plan screens stay synchronized.
- `backend/`
  The local Node.js backend used for lesson-16 study-step data.

Students should use these example assets only when the instructor directs them to a known-good reference path.
