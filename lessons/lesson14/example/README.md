# Lesson 14 Example Projects

This folder contains the instructor reference assets for lesson 14.

- `request-states-practice-reference/`
  A known-good Expo Router app that preserves the lesson-13 local-backend flow and gives the instructor a stable comparison app for lesson-14 robustness practice.
- `backend/`
  The local Node.js backend used for lesson-14 request-state testing.

Students should use these example assets only when the instructor directs them to a known-good reference path.
