# Lesson 14 Student README

This file contains the student-facing usage order for this lesson bundle.

1. Start with `work-session-checklist.md`.
2. Open `worked-example.md` to review the baseline target and file anchors.
3. Use `exercise.md` to complete the required tasks.
4. Use `recovery-paths.md` immediately if one foundation area is partial or blocked.
5. Open `success-criteria.md` to verify whether the work is actually stable.
6. Record status in `progress-tracker.md` before the checkpoint.

## Important Note
Students should begin with the work-session documents in this folder, not by opening older lesson exercises directly. Older lesson files are referenced only through `recovery-paths.md` when targeted repair is needed.
