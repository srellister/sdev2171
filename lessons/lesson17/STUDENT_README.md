# Lesson 17 Student README

This file contains the student-facing usage order for this lesson bundle.

1. Start with `starting-state-reference.md`.
2. Move into `forms-build-checklist.md` as the main path during class.
3. Use `local-vs-shared-form-state.md`, `validation-reference.md`, `starter-snippets.md`, and `troubleshooting-checklist.md` only when the checklist tells you to inspect a form-state or recovery step.
4. Record your current outcome in `form-status-tracker.md` if instructed.
5. Use the reference path in `example/` only if the instructor directs you to inspect it.
6. Complete `exercise.md` after class.

## Important Note
Students should not move every form field into Context while typing. The goal is to keep draft input local, validate it clearly, and save only the committed result into shared state.
