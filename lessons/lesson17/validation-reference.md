# Lesson 17 Validation Reference

Use this guide to keep validation simple and visible.

## Validation Rules In This Lesson
- session title is required
- at least one study step must already be selected before the form can save

## What Good Validation Looks Like Here
- the invalid submit path stays on the form screen
- one short message explains what must be fixed
- the user can correct the form and try again

## What This Lesson Does Not Need
- advanced regex rules
- multiple simultaneous error blocks
- server-side validation
- polished error animations

## Plain-Language Goal
The user should be able to tell:
- why the form did not save yet
- what to fix next
