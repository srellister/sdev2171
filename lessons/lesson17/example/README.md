# Lesson 17 Example Projects

This folder contains the instructor reference assets for lesson 17.

- `forms-flow-reference/`
  A known-good Expo Router app that keeps form draft values local, validates them, then saves the committed result into shared Context so another screen can display it.
- `backend/`
  The local Node.js backend used for lesson-17 study-step data.

Students should use these example assets only when the instructor directs them to a known-good reference path.
