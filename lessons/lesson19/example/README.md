# Lesson 19 Example Projects

This folder contains the instructor reference assets for lesson 19.

- `auth-flow-concepts-reference/`
  A known-good Expo Router app that demonstrates one public auth flow, one protected route group, one shared auth state provider, and one bearer-token request while preserving the existing study-plan feature line.
- `backend/`
  The local Node.js backend used for lesson-19 auth and protected study-step data.

Students should use these example assets only when the instructor directs them to a known-good reference path.
