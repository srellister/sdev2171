# Lesson 19 Student README

This file contains the student-facing usage order for this lesson bundle.

1. Start with `starting-state-reference.md`.
2. Move into `auth-flow-analysis-checklist.md` as the main path during class.
3. Use `auth-flow-map.md`, `auth-structure-map.md`, `bearer-request-reference.md`, and `troubleshooting-checklist.md` only when the checklist tells you to inspect a decision point.
4. Record your current outcome in `auth-status-tracker.md` if instructed.
5. Use the reference path in `example/` only if the instructor directs you to inspect it.
6. Complete `exercise.md` after class.

## Important Note
Students should not try to add secure storage or external auth services in this lesson. The goal is to understand the flow and structure clearly before building it in lesson 20.
