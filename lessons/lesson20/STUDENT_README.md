# Lesson 20 Student README

This file contains the student-facing usage order for this lesson bundle.

1. Start with `starting-state-reference.md`.
2. Use `quick-start-reference.md` before wiring requests.
3. Move into `auth-build-checklist.md` as the main path during class.
4. Use `provider-placement-reference.md`, `route-protection-reference.md`, `starter-snippets.md`, and `troubleshooting-checklist.md` only when the checklist tells you to inspect a setup or recovery step.
5. Record your current outcome in `auth-status-tracker.md` if instructed.
6. Use the reference path in `example/` only if the instructor directs you to inspect it.
7. Complete `exercise.md` after class.

## Important Note
Students should keep this lesson scoped to in-memory auth for the current app session. Session persistence belongs to lesson 21.
