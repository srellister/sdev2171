# Lesson 20 Example Projects

This folder contains the instructor reference assets for lesson 20.

- `auth-implementation-reference/`
  A known-good Expo Router app that demonstrates shared auth state, public auth routes, protected route gating, logout, and one first protected request while preserving the existing study-plan feature line.
- `backend/`
  The local Node.js backend used for lesson-20 auth and protected study-step data.

Students should use these example assets only when the instructor directs them to a known-good reference path.
