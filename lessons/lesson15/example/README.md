# Lesson 15 Example Projects

This folder contains the instructor reference assets for lesson 15.

- `state-sharing-problem-reference/`
  A known-good Expo Router app that demonstrates a local selection on one screen and a copied plan snapshot on another screen so the instructor can show why duplicated state drifts out of sync.
- `backend/`
  The local Node.js backend used for lesson-15 study-step data.

Students should use these example assets only when the instructor directs them to a known-good reference path.
