# Lesson 15 Student README

This file contains the student-facing usage order for this lesson bundle.

1. Start with `starting-state-reference.md`.
2. Move into `state-sharing-analysis-checklist.md` as the main path during class.
3. Use `navigation-parameter-limitations.md`, `scenario-map.md`, and `troubleshooting-checklist.md` only when the checklist tells you to inspect a limitation or decision point.
4. Record your current outcome in `state-readiness-tracker.md` if instructed.
5. Use the reference path in `example/` only if the instructor directs you to inspect it.
6. Complete `exercise.md` after class.

## Important Note
Students should not begin by trying to implement Context on their own in this lesson. The goal is to recognize the problem clearly first, not to jump ahead to the solution.
