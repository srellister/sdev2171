# Lesson 11 Debugging Status Tracker

Use this tracker at the midpoint or checkpoint if your instructor asks for a quick status update.

## Status options
- `resolved`
  You reproduced the bug, inspected evidence, and resolved it.
- `partial`
  You reproduced the bug and gathered evidence, but the fix is incomplete.
- `blocked`
  The debugging path cannot continue during class without recovery support.

- Current status:
- Current bug symptom:
- Main tool clue used:
- Current file you are checking:
- Last useful log or comparison:
- Current hypothesis:
- Next action:

## Suggested check order
1. visible symptom
2. most relevant state value
3. related handler or condition
4. related render output
5. known-good reference comparison if needed

## Instructor checkpoint question
Be ready to answer:
- What symptom did you reproduce?
- What evidence did you inspect first?
- What tool clue helped you most?
- What happened after the retest?
