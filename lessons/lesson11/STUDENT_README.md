# Lesson 11 Student README

This file contains the student-facing usage order for this lesson bundle.

1. Start with `debugging-lab-checklist.md` during class.
2. Stay on `debugging-lab-checklist.md` as the main path unless you need help with one specific issue.
3. Check `starting-state-reference.md` only if you are unsure whether your project is ready.
4. Use `debugging-reference.md`, `starter-snippets.md`, and `troubleshooting-checklist.md` only when the checklist tells you to inspect a tool, log, or recovery path.
5. Record your current debugging outcome in `debugging-status-tracker.md` if instructed.
6. Use the reference path in `example/` only if the instructor directs you to inspect it.
7. Complete `exercise.md` after class.

## Important Note
Students should not begin with `exercise.md`. The guided debugging lab and support references come first.
