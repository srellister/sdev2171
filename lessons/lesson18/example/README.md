# Lesson 18 Example Projects

This folder contains the instructor reference assets for lesson 18.

- `context-forms-practice-reference/`
  A known-good Expo Router app that demonstrates the stable integrated workflow from lessons 16 and 17: shared selected steps, local draft form state, validation, and a submitted shared summary result.
- `backend/`
  The local Node.js backend used for lesson-18 study-step data.

Students should use these example assets only when the instructor directs them to a known-good reference path.
