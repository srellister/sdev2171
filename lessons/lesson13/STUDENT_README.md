# Lesson 13 Student README

This file contains the student-facing usage order for this lesson bundle.

1. Start with `starting-state-reference.md` and `local-backend-reference.md`.
2. Move into `loading-error-build-checklist.md` as the main path during class.
3. Use `request-states-reference.md`, `starter-snippets.md`, and `troubleshooting-checklist.md` only when the checklist tells you to inspect a request-state or recovery step.
4. Record your current outcome in `request-status-tracker.md` if instructed.
5. Use the reference path in `example/` only if the instructor directs you to inspect it.
6. Complete `exercise.md` after class.

## Important Note
Students should not begin with `exercise.md`. The guided in-class request-state build and local-backend setup come first.
