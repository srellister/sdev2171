# Lesson 13 Example Projects

This folder contains the instructor reference assets for lesson 13.

- `loading-error-reference/`
  A known-good Expo Router app that shows loading, success, and error states while requesting the local lesson backend.
- `backend/`
  The local Node.js backend used for lesson-13 request-state testing.

Students should use these example assets only when the instructor directs them to a known-good reference path.
